# Реализация численных методов (C / C++)

> Этот репозиторий представляет собой архив моих старых лабораторных работ по предмету «Численные методы» выполненных на втором курсе. С момента  написания этого кода мои навыки улучшились, поэтому я планирую провести рефакторинг и выложить обновленную версию.

---
## 🛠 Стек технологий и инструменты
*   **Язык программирования:** C / C++ (Стандарты ISO C99 / C++14)
*   **Среда разработки:** Visual Studio 2022 (компилятор MSVC).
*   **Визуализация данных:** Отрисовка графиков в консоли через WinAPI / GDI (`HDC`, `LineTo`)
