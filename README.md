# Реализация численных методов (C / C++)

> Этот репозиторий представляет собой архив моих старых лабораторных работ по предмету «Численные методы», выполненных на втором курсе. С момента написания кода мои навыки улучшились, поэтому был проведен рефакторинг.

---
## 🛠 Стек технологий и инструменты
*   **Язык программирования:** C (в процедурном стиле, сборка под стандарт C++14)
*   **Среда разработки:** Visual Studio 2022 (компилятор MSVC)
*   **Визуализация данных:** Отрисовка графиков в консоли через WinAPI / GDI (`HDC`, `LineTo`) 
---

## 🚀 Запуск проекта
1. Скачайте репозиторий или клонируйте его с помощью `git clone`.
2. Откройте файл решения (`.sln`) в Visual Studio.
3. В **Обозревателе решений** нажмите правой кнопкой мыши на нужный проект и выберите "Назначить запускаемым проектом".
4. Запустите программу нажатием `Ctrl + F5` (для корректного отображения графиков рекомендуется использовать классическую консоль Windows).
